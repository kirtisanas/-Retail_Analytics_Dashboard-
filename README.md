# Retail Analytics Dashboard

## Project Overview

This project is a Retail Analytics Dashboard created using Microsoft Excel and SQL. It analyzes retail sales data to understand sales performance, profit, customer segments, product performance, and regional trends.

## Objectives

- Analyze overall retail sales and profit
- Identify top-performing products and categories
- Compare sales across regions and cities
- Analyze customer segments
- Understand monthly sales and profit trends
- Calculate profit margins

## Dataset

The dataset contains retail transaction information with the following fields:

- Order ID
- Order Date
- Customer ID
- Segment
- Region
- City
- Category
- Product
- Quantity
- Sales
- Profit

## Tools & Technologies

- Microsoft Excel
- SQL / MySQL
- Data Analysis
- Data Visualization

## Dashboard

The Excel dashboard provides a visual overview of key retail business metrics and trends.

## SQL Analysis

SQL queries were created to analyze:

- Total Sales
- Total Profit
- Total Quantity
- Total Orders
- Sales by Region
- Profit by Region
- Sales and Profit by Category
- Sales by Customer Segment
- Top Products
- Monthly Sales
- Monthly Profit
- Sales by City
- Profit Margin by Category
